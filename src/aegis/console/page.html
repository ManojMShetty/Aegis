Left of the trust boundary

The untrusted input

Text a tool returned this turn. Attacker-controlled by assumption: the console never grants it authority, whatever it says about itself. Edit it freely — taint is matched against these exact bytes.

Empty means no tool returned anything this turn — a different statement from “a tool returned nothing suspicious”. Press Run after editing. Try pasting a fake fence such as <<UNTRUSTED_abc>> and then switching L2 off: that is a break-out attempt, and the guard panel names it as one.

What the guard did to the input

L1 records where the text came from. L2 rewrites it so the model can see where data starts and stops. L3 reads it for injection patterns and raises advisory flags. None of these three refuses anything — that is L5's job.

Argument trace

One row per argument of the proposed call. An argument is untrusted because its text appears in what a tool returned this turn — not because it looks malicious, not because it is on a list. matched_tools names the tool whose output contains it; that match, and nothing else, is what drops the tier.
